# Control de deudas — Android

Aplicación Android local basada en WebView. No requiere internet y guarda todos los datos en el teléfono.

## Compilar

El flujo de GitHub Actions incluido compila automáticamente el APK. El archivo resultante aparece en **Actions → Compilar APK → Artifacts** con el nombre `CONTROL-DE-DEUDAS-APK`.

El APK es una compilación de prueba firmada por Android. Para instalarla, hay que permitir temporalmente la instalación de aplicaciones desconocidas para el navegador o gestor de archivos usado.
